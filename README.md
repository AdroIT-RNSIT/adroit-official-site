# ☁️ AdroIT Official Site

This repository contains the official AdroIT platform built using React, Supabase, and Vercel following scalable cloud-native architecture principles. The project is designed for collaborative development with structured workflows and open-source standards.

---

## 🚀 Project Overview

The AdroIT Official Site is a full-stack web application developed under the Cloud Computing Domain. The architecture separates frontend and backend services to ensure maintainability, scalability, and smooth team collaboration.

---

## ⚙️ Prerequisites

Install the following:

* Node.js (v16 or higher)
* npm
* Git

Check versions:

```
node -v
npm -v
git --version
```

---

## 📥 Getting Started

Clone the repository:

```
git clone https://github.com/AdroIT-RNSIT/adroit-official-site.git
cd adroit-official-site
```

---

## 💻 Local Development Setup

### Frontend

```
cd frontend
npm install
npm run dev
```

Open browser:

```
http://localhost:5173
```

## 🌿 Development Workflow

### Branch Strategy

Do NOT push directly to `main`.

Create feature branches:

```
git checkout -b feature/<feature-name>
```

Examples:

* feature/team-page
* fix/navbar-alignment
* docs/update-readme

Submit changes via Pull Requests.

## 🧪 Coding Guidelines

* Maintain separation between frontend and backend logic.
* Avoid unnecessary dependencies.
* Keep components modular and reusable.

---

## 🧹 Troubleshooting

Dependency issues:

```
npm cache clean --force
npm install
```

Port already in use:

```
npm run dev -- --port 5173
```
